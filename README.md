# Petora API

API de Petora construida con [NestJS](https://nestjs.com/). Este proyecto se encuentra en desarrollo y servirá como base para la gestión de mascotas.


## Paso1: Clonacion del repositorio

```bash
  git clone https://github.com/TpLink777/Petora.git
```

## Paso 2: Instalación

```bash
pnpm install
```

## Paso 3: Configuracion de variables de entorno desde el archivo .env.example y renombrar a .env


## Paso 4: Levantar la BD

```bash
  docker-compose up -d
```

## Paso 5: Levantar el proyecto

```bash
  pnpm start:dev
```

## Paso 6: Ejecuitar la semilla de datos (SEED)

```bash
  http://localhost:3000/api/petora/seed
```
